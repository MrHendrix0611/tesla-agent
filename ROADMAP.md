# Roadmap — Tesla Agent

**Criador:** Guilherme Hendrik · [GitHub](https://github.com/MrHendrix0611)

A V0.6.0 é a última versão de código incluída neste pacote. As próximas funcionalidades são propostas, não entregas concluídas.

| Versão planejada | Objetivos |
|---|---|
| V0.7.0 | API local (FastAPI), dashboard web, chat, diffs, aprovações, extensão VS Code inicial. |
| V0.8.0 | Aplicação desktop independente, reutilizando interface web e harness Python. |
| V0.9.0 | Editor integrado, explorador de arquivos e terminal para experiência Tesla IDE. |
| V1.0.0 | Segurança, distribuição, qualidade e integração de funcionalidades em produto estável. |

Nenhum recurso futuro é garantido até sua implementação e validação.
