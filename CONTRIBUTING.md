# Contribuindo para o Tesla Agent

**Criador:** [Guilherme Hendrik](https://github.com/MrHendrix0611)

1. Trabalhe sobre a versão mais recente em `versions/v0.6.0/` ou solicite confirmação do local de evolução do projeto.
2. Instale as dependências apenas da versão em que estiver trabalhando.
3. Execute `py -m unittest discover -s tests -v` sempre que houver testes na versão.
4. Não inclua chaves, `.env`, logs, caches, `.tesla/` nem conteúdo privado em pull requests.
5. Descreva problema, passos para reproduzir, comportamento esperado e validação.
6. Mantenha a CLI e a política de confirmação de ferramentas sensíveis.

A licença de contribuição ainda deve ser definida pelo mantenedor antes da distribuição sob uma licença aberta.
